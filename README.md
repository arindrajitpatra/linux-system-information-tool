
# Linux System Information Tool

A Bash script that collects and displays essential Linux system information in a structured format.

## Features

- Current user
- Hostname
- Operating system
- Kernel version
- Current directory
- Current date & time
- System uptime
- Logged-in users
- Disk usage
- Memory usage
- CPU information
- IP address

## Technologies

- Bash
- Linux CLI

## Project Structure

```
project-01-system-info/

│   └── system_info.sh
├── output/

```

## Usage

```bash
chmod +x src/system_info.sh
./src/system_info.sh
```
